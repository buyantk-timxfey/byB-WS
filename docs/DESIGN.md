# Дизайн-система byBuka 2.0 — «Liquid Glass»

> Визуальный язык: Apple iOS 26/27 **Liquid Glass**. Эстетика — Apple; банковские экраны — в духе **Apple Card**.
> Реализация: Vue 3 + Tailwind, CSS `backdrop-filter`, spring-анимации. Стек — см. `CRM-PLAN.md`.

## Согласованные решения по дизайну

| Параметр | Решение |
|----------|---------|
| Тема | **Светлая + тёмная**, авто по системе |
| Акцент | **Монохром «как в iOS», без брендового цвета**; цвет — только семантический |
| Плотность | **Гибрид**: воздушные карточки/виджеты + плотные читаемые таблицы в журналах |
| Дашборд | **Настраиваемые виджеты** (drag, размеры S/M/L, добавить/скрыть) |
| Банк-референс | **Apple Card** (минимализм, крупные цифры, категории) |
| Стекло/перформанс | **Полное живое стекло** (устройства мощные) + фолбэк только для a11y |
| Шрифт/иконки | **SF Pro** (system-ui) + иконки в стиле **SF Symbols** |

---

## 1. Принципы Liquid Glass
1. **Материал, а не плоскость.** Поверхности — слои стекла: размытие фона + полупрозрачная заливка + преломление света по краю.
2. **Глубина через слои.** Контент → стеклянная панель → плавающие контролы. Каждый слой ярче и «выше» предыдущего.
3. **Свет и вибранси.** Текст/иконки на стекле — vibrancy (подмешивают фон), тонкая верхняя световая грань (hairline highlight).
4. **Непрерывность форм.** Continuous corner radius (superellipse), крупные радиусы, мягкие тени.
5. **Жидкое движение.** Пружинные переходы, «оживание» при касании, плавная морфология (sheet растёт из кнопки).
6. **Цвет от контента.** База монохромна; цвет несут данные (приход/расход/статус), а не оформление.

---

## 2. Цвет

### База (монохром, адаптивная)
- **Тёмная**: фон — глубокий graphite-градиент (#0B0B0F → #15161C), стекло — белое с alpha 6–14%.
- **Светлая**: фон — мягкий off-white градиент (#F2F3F7 → #FFFFFF), стекло — белое с alpha 50–70% + блюр.
- **Ink** (основной контент): near-white в тёмной / near-black в светлой. Первичные кнопки — ink-заливка (как iOS «чёрная/белая» кнопка), без цветного бренда.

### Семантическая палитра (единственный источник цвета)
| Назначение | Цвет |
|-----------|------|
| Приход / прибыль / успех | `#34C759` (iOS green) |
| Расход / долг / ошибка | `#FF3B30` (iOS red) |
| Внимание / ETA истёк | `#FF9F0A` (amber) |
| Инфо / в пути | `#0A84FF` (только для статуса, не как бренд-акцент) |
| Нейтральный статус | стекло + ink-secondary |

Категории операций (Apple Card style) — мягкие пастельные «таблетки» цвета per статья/группа.

---

## 3. Материалы (уровни стекла)
| Уровень | Применение | blur | Заливка (тёмная) | Грань |
|---------|-----------|------|------------------|-------|
| L0 фон | подложка | — | градиент | — |
| L1 панель | карточки, виджеты, таблицы | 24–32px saturate(180%) | white 8% | top hairline 1px white 12% |
| L2 плавающий | сайдбар, таб-бар, поповеры, FAB | 36–48px | white 14% | highlight + тень глубины |
| L3 модал | drawer/sheet/диалог | 48px | сильнее + затемнение фона | выраженная тень |

Фолбэк (a11y / `prefers-reduced-transparency`): непрозрачное «frosted» (сплошной близкий к стеклу тон), те же тени/радиусы.

---

## 4. Форма, сетка, плотность
- **Радиусы**: контролы 12px, карточки/виджеты 20–24px, sheets 28px — continuous.
- **Spacing scale**: 4/8/12/16/20/24/32/40.
- **Гибрид плотности**:
  - Карточки/виджеты/формы — воздушные (padding 16–24).
  - **Журналы-таблицы** — компактные строки (40–44px), липкая стеклянная шапка, зебра через тонкий divider, плотно но читаемо.

---

## 5. Типографика (SF Pro)
- Семейство: `-apple-system, "SF Pro Display", "SF Pro Text", system-ui` (нативно на Apple, грациозный фолбэк).
- Шкала: Large Title 34 / Title 28 / Title2 22 / Headline 17 semibold / Body 17 / Subhead 15 / Footnote 13 / Caption 11.
- Цифры — табличные (`font-variant-numeric: tabular-nums`) для сумм в таблицах и банке.

## 6. Иконки
- Стиль **SF Symbols**: монолинейные, скруглённые, весовая синхронизация со шрифтом.
- Реализация: набор в стиле SF (напр. локальный SVG-сет) вместо Lucide; единый размер/вес.

## 7. Движение
- Пружины (spring): открытие sheet/drawer, drag виджетов, нажатия (scale 0.97 + «жидкая» отдача).
- Переходы страниц — лёгкий fade+scale, без «прыжков».
- Уважение `prefers-reduced-motion` (мгновенные состояния).

---

## 8. Компоненты
- **Навигация**: десктоп — плавающий стеклянный сайдбар (L2); мобайл — плавающий стеклянный таб-бар + «Ещё»-sheet.
- **Виджеты/карточки**: L1 стекло, заголовок + контент, размеры S/M/L.
- **Таблицы-журналы**: стеклянная липкая шапка, компактные строки, инлайн-статусы-«таблетки», свайп-экшены на мобайле.
- **Формы документов**: стеклянные секции, инлайн-табличная часть, проведение Ctrl+Enter, авто-подстановка.
- **Кнопки**: primary — ink-заливка; secondary — стекло; деструктив — red. Крупный тач-таргет (44px).
- **Sheets/Drawers/Диалоги**: L3, морфятся из источника, drag-to-dismiss на мобайле.
- **Тосты/уведомления**: стеклянные «пилюли» сверху, авто-скрытие.
- **Статусы**: «таблетки» (Ожидает/В пути/Завершено; Оплачено/Частично/Не оплачено) семантическим цветом.

---

## 9. Дашборд — настраиваемые виджеты
- Сетка адаптивная; виджеты **S (1×1) / M (2×1) / L (2×2)**.
- Режим редактирования (как iOS): «джигл», перетаскивание, изменение размера, добавить/скрыть, сохранение раскладки в профиле.
- Каталог виджетов: KPI/прибыль, Деньги по счетам, Дебиторка/Кредиторка, Трекер поставок (кольца), Календарь ETA, Склад/залежалое, Неразнесённые строки, Почта по ящикам, Заметки/напоминания.
- Реализация: CSS Grid + библиотека drag/resize (напр. muuri/gridstack-подход), стеклянные карточки.

---

## 10. Банк — в духе Apple Card
- **Карточки счетов**: крупная стеклянная/градиентная карта, баланс крупно, мини-тренд.
- **Лента операций**: строка = аватар/иконка контрагента + название + категория-«таблетка» + сумма (зелёный приход / обычный расход), сгруппировано по датам.
- **Деталь операции**: крупная сумма, контрагент, статус сверки, связанный документ, кнопки сопоставления.
- **Экран сверки**: две колонки (строки выписки ↔ кандидаты-документы), авто-подбор, подтверждение свайпом/кликом, прогресс «разнесено N из M».
- **Аналитика**: расходы по категориям (кольца/бары), как в Apple Card «Spending».

---

## 11. Реализация на стеке
- **Токены** — в Tailwind config (цвета, радиусы, тени, стекло-утилиты) + CSS-переменные для тем.
- **Стекло** — утилита-класс: `backdrop-filter: blur() saturate()` + alpha-fill + hairline + shadow; авто-фолбэк через `@supports` и `prefers-reduced-transparency`.
- **Темы** — `color-scheme` + переменные, переключение по `prefers-color-scheme` (+ ручной тумблер).
- **Движение** — CSS springs / @vueuse motion.
- **Виджеты** — grid-движок с сохранением раскладки.
- **PWA** — статус-бар `black-translucent`, safe-area insets, плавающие панели с учётом «чёлки»/home-indicator.
